# CRM Sales Analytics Dashboard

This project focuses on building interactive dashboards and performing in-depth data analysis for core CRM metrics. Using **Excel**, **Power BI**, **Tableau**, and **MySQL**, the goal was to uncover actionable business insights that support sales strategy and performance monitoring.

## 🔧 Tools & Technologies

- **Excel**
- **Power BI**
- **Tableau**
- **MySQL**

## 📊 Key Features

- **Dynamic Dashboards**:  
  Created visually intuitive dashboards to track key CRM KPIs, such as:
  - Revenue projections  
  - Conversion ratios  
  - Win/Loss metrics  
  - Sales funnel performance  

- **Automated Data Pipelines**:  
  Connected MySQL databases to Power BI and Tableau to enable automated data refresh and real-time analytics, reducing manual reporting efforts.

- **Segmentation Analysis**:  
  Performed detailed breakdowns of leads and opportunities by:
  - Lead source  
  - Industry  
  - Sales stage  
  - Opportunity type  

- **Comparative Business Insights**:  
  Conducted analysis on:
  - Forecasted vs. actual revenue  
  - Closed-won performance vs. total deal volume  

## 📈 Outcome

This analysis provided a comprehensive view of the sales pipeline and highlighted trends that helped improve decision-making, resource allocation, and revenue forecasting accuracy.
